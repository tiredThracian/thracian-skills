# Style Extractor & Enterprise Rule Generator Skill (English & Turkish 🇹🇷)

Use this skill to analyze writing samples, codebases, or technical documentation (in **English** or **Turkish / Türkçe**), extract personal writing signatures or enterprise domain standards, and generate **deterministic Antigravity Rule files (`.gemini/config/rules/*.md` / `.agent/rules/*.md`)** or **Custom Skill Style Guides (`SKILL.md`)**.

## 📐 Enterprise Rule Creation Methodology

Derived from enterprise defense and software engineering rule specifications (e.g. `aselsan-know-how-transferi`), rules generated by this skill follow a 5-part structural pattern:

### 1. YAML Frontmatter & Title
Every rule file MUST begin with clean metadata and a normative title:
```markdown
---
description: [Single-sentence mandate summary]
trigger: always_on  # Options: always_on | manual
---

# [Normative Rule Title in Title Case or Türkçe Format]
```

### 2. RFC 2119 Normative Imperatives
Rules MUST use bold, capitalized normative terms:
- **Turkish:** **ZORUNLUDUR** (MUST), **YASAKTIR** (MUST NOT / FORBIDDEN), **TERCİH EDİLMELİDİR** (SHOULD), **ASLA** (NEVER).
- **English:** **MUST**, **MUST NOT**, **SHOULD**, **SHOULD NOT**, **NEVER**.

### 3. Do's & Don'ts Contrast Examples (Yanlış vs. Doğru Kullanım Lists)
Rules MUST include explicit bad vs. good contrast examples to eliminate AI ambiguity:
```markdown
### ❌ Yanlış Kullanımlar (Incorrect):
- Sinyal işleme ısınma (warmup) algoritması. (Parantez içi gereksiz çeviri)
- Sıkıştırma motoru / Oturum motoru. (Mecazi "engine/motor" kullanımı yapaydır)

### ✅ Doğru Kullanımlar (Correct):
- Sinyal işleme ısınma algoritması.
- Sıkıştırma mekanizması / Oturum altyapısı.
```

### 4. Banned & Mandatory Terminology Matrix
Rules MUST formulate an explicit table mapping prohibited terms to approved equivalents:

| Prohibited / Banned Term (Yasaklı) | Mandatory Replacement (Doğru/Zorunlu) | Context / Rationale |
| :--- | :--- | :--- |
| **tampon / tamponlama** | **buffer / bufferlama** | Forced translation creates ambiguity. |
| **orkestre etmek** | **yönetmek / koordine etmek** | Overused metaphorical AI cliché. |
| **kilit / kilitlenmesiz** | **lock / lock-free** | Use native concurrency terminology. |
| **dijital** | **sayısal** | Official technical standard. |

### 5. Ground Truth & Verification Requirements
Rules MUST define explicit verification criteria requiring AI agents to cross-check outputs against authoritative source code, database schemas, or physical specs before declaring success (*"projenin kaynak kod dosyalarını inceleyerek teyit etmek zorundadır"*).

## 🎛️ Language Flags & Modes

*   **`--auto`** *(Default)*: Automatically detects sample language (English, Turkish, or Bilingual) and applies matching analysis.
*   **`--tr` / `--turkish`**: Applies Turkish morphosyntactic analysis, Turkish RFC 2119 terms (**ZORUNLUDUR**, **YASAKTIR**), and Turkish Anti-AI Purge Matrix.
*   **`--en` / `--english`**: Applies English stylometrics and English Anti-AI Purge Matrix.

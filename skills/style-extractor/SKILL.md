## 📐 Enterprise Rule Creation Methodology

Derived from production defense software engineering standards in `D:\Work\Projekts\aselsan-know-how-transferi`, rules generated by this skill cover 7 core categories:

1. **Ground Truth Code Reference Checks (`codebase_reference_check`):** Source code is the single source of truth. Mandatory verification of function bodies, member variables, DB schemas (`Int64`, `DateTime`), and log formats.
2. **Terminology & Language Regulations (`documentation_language`):** Hard prohibitions on parenthetical inline translations like `Header (Başlık)` and mandatory terminology matrices (*"buffer"* instead of *"tampon"*, *"lock-free"* instead of *"kilitlenmesiz"*, *"sayısal"* instead of *"dijital"*).
3. **Document Naming, Placement & Hierarchy (`document_naming_and_placement`):** Naming pattern `[TYPE]_[PROJECT].docx` in `[Project]/docs/`. H1 headers in ALL CAPS, H2/H3 in Title Case. No line numbers in code links (`#L123`).
4. **Caption & Compiler Syntax (`captions`):** Mandatory `%% table_caption:`, `%% static_image:`, and `%% caption:` for Mermaid blocks. Hard ban on raw horizontal dividers (`---`) in markdown body.
5. **Scripting & Escaping Safety (`xml_html_writing_safety`):** Escaping placeholders (`LT`/`GT`) in Python generators to prevent rich-text parser corruption (`[[ORCA_RICH_MD...]]`).
6. **Project & System-Specific Rules (`ytet_project_rules`):** Banning generic terms (*"uygulama"*, *"program"*) in favor of the official system unit name (**`İRİS`**), mandatory 4-column test table formats, unbulleted parameter blocks.
7. **Document Content Conformance (`document_content_conformance`):** Mandatory justification of inapplicable items, 100% cross-document terminology alignment across YGO, YTT, YTET, YTER, YUO.

Rules synthesized for `.gemini/config/rules/*.md` or `.agent/rules/*.md` follow this format:

```markdown

## 1. Core Directives & Mandates
- AI agents **ZORUNLUDUR / MUST** [directive].
- AI agents **YASAKTIR / MUST NOT** [prohibited action].

## 2. Terminology & Prohibited Words Matrix

| Yasaklı Terim (Prohibited) | Doğru / Zorunlu Karşılık (Mandatory) | Rationale |
| :--- | :--- | :--- |
| `[banned_1]` | `[approved_1]` | [Reason] |

## 3. Contrast Examples

### ❌ Yanlış Kullanım (Incorrect):
> [Bad example]

### ✅ Doğru Kullanım (Correct):
> [Good example]

## 4. Ground Truth Verification Requirement
AI agents **MUST** verify all claims directly against source code files or database schemas.
```
